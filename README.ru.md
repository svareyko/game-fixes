# game-fixes

Фиксы, патчи и небольшие моды для игр на ПК. Каждый разобран до настоящей причины — по дампу,
дизассемблеру, коду самого сайта — и каждый можно откатить.

## Как пользоваться

В каждой папке свой `README.ru.md`, написанный для игроков, а не для программистов: как узнать
свою проблему, что понадобится, установка по шагам, как проверить, что сработало, как откатить.

- **Юзерскрипт** ставится одним кликом из своего README.
- **Моды Minecraft** лежат на странице [Releases](https://github.com/svareyko/game-fixes/releases).
- **Патчи игр** — небольшие скрипты на Python, рядом с ними `apply.bat` / `check.bat` / `revert.bat`.
  [Скачайте репозиторий архивом ZIP](https://github.com/svareyko/game-fixes/archive/HEAD.zip),
  распакуйте куда угодно, откройте папку своей игры и идите по её README. Понадобится
  [Python 3](https://www.python.org/downloads/) (при установке поставьте галочку *Add python.exe to PATH*).

## Чего ждать от здешних патчей

- **Сначала проверка, потом запись.** Патчер сверяет байты, которые собирается менять, с
  ожидаемыми и отказывается трогать незнакомую версию. Обновление игры сдвигает код; молча
  пропатченный не тот адрес хуже, чем отказ.
- **Сначала бэкап**, и `revert` возвращает оригинал.
- **`check.bat` ничего не меняет** — только рассказывает, что нашёл и что сделал бы `apply`.
- **Ничего никуда не отправляется.** Ни телеметрии, ни обращений в сеть, ни установщиков.
  Обычный исходный код, который можно прочитать.
- **Файлы игр здесь не распространяются.** Вы патчите свою копию.
- Обновление игры или «проверка целостности файлов» возвращает оригинальные файлы и снимает патч.
  Это нормально; запустите патчер снова — он скажет, поддерживается ли новая версия.

В каждом README честно сказано, что проверено игрой, а что только на бумаге.

## Как это работает

Технические разборы — причина, адреса, байты «было → стало», почему правка безопасна, как
перенести её на новую версию игры — лежат в `docs/how-it-works.ru.md` каждой папки.
