# Ore Map — метки алмазов и незерита на большой карте Xaero

**Небольшой клиентский мод под Minecraft 26.2 и Fabric.** Он проходит по чанкам, которые
твоя игра уже загрузила, находит алмазную руду и древние обломки и ставит их на
[Xaero's World Map](https://modrinth.com/mod/xaeros-world-map) метками с глубиной в
подписи:

```
Diamonds x8 Y-59
Netherite Y15
```

*Minecraft 26.2 · Fabric · Xaero's Minimap · Xaero's World Map · метки алмазов на карте ·
метки незерита · поиск древних обломков · руда на карте · только одиночная игра и
локальная сеть*

[English version](README.md) · [Как это устроено](docs/how-it-works.ru.md) ·
[Другие моды этого репозитория](../README.ru.md)

> **Только одиночная игра и своя локальная сеть.** На публичном сервере такой мод — это
> чит-рентген, поэтому он проверяет, где ты находишься, и **сам выключается** везде,
> кроме одиночных миров и серверов в локальной сети. Точное правило — в разделе
> [Где работает и где отказывается](#где-работает-и-где-отказывается).

---

## Что он делает

- Отмечает жилы **алмазной руды** и **древних обломков** на большой карте Xaero.
- **Одна метка на жилу**, а не на каждый блок. В подписи — что это, сколько блоков и
  глубина: `Diamonds x8 Y-59` — жила из восьми блоков, нижний блок на Y -59. Метка
  указывает ровно на этот нижний блок.
- Алмазы — бирюзовые метки с буквой `D`, древние обломки — тёмно-красные с `N`.
- Выкопанная жила пропадает с карты примерно за секунду.
- **По умолчанию выключен.** Пока выключен — не делает вообще ничего: не сканирует, не
  занимает память, меток нет. Включаешь, когда идёшь копать, выключаешь, когда закончил.
- Метки видны **только на большой карте**. Миникарту они не засоряют и маяками посреди
  экрана не висят. Так задумано.

Готового мода с такой функцией под Minecraft 26.2 не нашлось — поэтому появился этот.

### Какие именно блоки

| Метка | Блоки |
|---|---|
| `Diamonds` | `minecraft:diamond_ore`, `minecraft:deepslate_diamond_ore` |
| `Netherite` | `minecraft:ancient_debris` |

Больше ничего. Блоки разных типов в одну жилу не склеиваются, даже если лежат вплотную.

### Как далеко он видит

**Это радар вокруг тебя, а не карта сокровищ.** Игра знает только те чанки, которые ей
прислал сервер, — то есть в пределах дальности прорисовки. Дальше мод заглянуть не может,
и ни один клиентский мод не может.

| Ограничение | Значение |
|---|---|
| Где ищется руда | при включении — в квадрате 23×23 чанка вокруг тебя; дальше — в каждом чанке, который игра загрузит, пока мод включён |
| Метки показываются в радиусе | **160 блоков** от тебя, по прямой, с учётом высоты |
| Меток на один тип руды | не больше **80**, берутся ближайшие |
| Как часто набор обновляется | раз в секунду |
| После включения | окрестности заполняются примерно за две секунды, от ближних к дальним |

Раз в 160 блоков входит и высота, с поверхности вбок видно меньше: с Y 64 до алмазной
жилы на Y -54 уже 118 блоков вниз, так что в стороны остаётся около 108. Внизу, в
пещерах, работают все 160.

**Один пробел, о котором стоит знать.** Чанки, которые в момент включения уже были
загружены, но лежали за пределами этих 23×23, не просматриваются, пока игра не загрузит
их заново. При большой дальности прорисовки долгий путь в одну сторону может завести в
такую область, и новые метки перестанут появляться. Набери `/oremap off` и `/oremap on` —
мод заново просмотрит окрестности твоего нового места.

## Как пользоваться

Открой чат и набери:

```
/oremap on        включить метки
/oremap off       выключить и всё освободить
/oremap status    что происходит прямо сейчас
```

Потом открой большую карту Xaero (клавиша `M`, если не менял).

Есть и клавиша: **`K`** переключает метки, над горячей панелью появляется подтверждение.
Переназначается в «Настройки → Управление → Назначение клавиш → Разное → Метки руды:
вкл/выкл».

**Команда — надёжный способ, клавиша — для удобства.** Minecraft отдаёт нажатия моду,
только пока не открыт ни один экран. При открытой карте, инвентаре или любом меню `K`
уходит этому экрану, и ничего не происходит — со стороны выглядит как «мод сломан».
У команды такой ловушки нет.

При каждом запуске игры мод выключен: выбор не сохраняется.

### Если ничего не появилось — `/oremap status`

```
[Ore Map] markers: ON (switch with /oremap on, /oremap off or the K key)
[Ore Map] working here: allowed — single-player world (integrated server)
[Ore Map] link to Xaero: ok
[Ore Map] chunks with ore: 212, in the scan queue: 0
[Ore Map] Diamonds: veins found 640, sent to the map 37
[Ore Map] Netherite: veins found 0, sent to the map 0
[Ore Map] marker radius 160 blocks, cap 80 per type; markers are on the world map only
```

(Числа — для примера.) Читай сверху вниз — видно, на каком шаге всё остановилось:

| Строка | Если в ней | Это значит |
|---|---|---|
| `markers` | `off` | ты не включил метки — после каждого запуска игры они выключены |
| `working here` | `NOT ALLOWED — …` | ты на сервере, который мод считает публичным; причина написана дальше |
| `link to Xaero` | `BROKEN` | миникарты Xaero нет или она обновилась и изменилась внутри; ошибка — в `logs/latest.log` |
| `veins found` | `0` | в загруженных чанках такой руды нет (например, древних обломков в обычном мире не бывает) |
| `sent to the map` | `0`, хотя жилы найдены | все жилы дальше 160 блоков — спустись глубже или подойди ближе |

Сообщения в чате и подписи меток — на английском. Переведено только название клавиши в
настройках управления (английский и русский).

## Где работает и где отказывается

Проверка устроена как **белый список**: разрешено только заведомо локальное, всё
неопознанное считается публичным. Порядок такой:

| № | Ситуация | Итог |
|---|---|---|
| 1 | Одиночный мир, в том числе открытый через **«Открыть для сети»** | **работает** |
| 2 | Игра не знает, что это за сервер | выключен |
| 3 | Мир, который игра сама нашла в локальной сети, — в списке сетевой игры он подписан **«Мир в локальной сети»** | **работает** |
| 4 | Realms | выключен |
| 5 | Любой другой сервер: решает **адрес, который ты вписал** в запись сервера | см. ниже |

В правиле 5 порт отбрасывается, остальное сравнивается как текст:

| Адрес | Итог |
|---|---|
| `localhost`, `::1`, `0:0:0:0:0:0:0:1` | **работает** |
| `10.x.x.x`, `127.x.x.x`, `192.168.x.x`, `172.16.x.x`–`172.31.x.x`, `169.254.x.x` | **работает** — частные и link-local адреса IPv4 |
| IPv6, начинающийся с `fc`, `fd`, `fe8`, `fe9`, `fea`, `feb` | **работает** — unique local и link-local IPv6 |
| голое имя машины без точек, например `my-pc` или `MY-PC:25565` | **работает** — такое имя бывает только в локальной сети |
| имя с окончанием `.local`, `.lan`, `.home`, `.internal`, `.localdomain` | **работает** |
| всё остальное — `mc.example.net`, `8.8.8.8`, `192.168.0.10.evil.com` | **выключен**, причина пишется в лог |

Имя намеренно **никогда не проверяется через DNS**: ответ может поменяться, а тихо
включиться на публичном сервере из-за одного запроса недопустимо. Имя, которое лишь
*начинается* как локальный адрес (`192.168.0.10.evil.com`, `localhost.example.com`),
считается публичным.

На сервере, где мод выключен, `/oremap on` всё равно ответит «ore markers are on», но
ничего не сканируется и ничего не появится. Причину покажет `/oremap status`, а в логе
будет строка вида `[oremap] disabled: public server mc.example.net - ore is not shown`.

### Честная игра

Проверка не пускает мод на публичные серверы, но правил конкретного сервера она прочитать
не может. **Не используй мод там, где такие моды запрещены**, и не используй его против
людей, которые на это не соглашались, — это касается и домашнего сервера, на котором ты
играешь с друзьями. Сомневаешься — спроси владельца сервера. Убрать или ослабить
проверку, чтобы пользоваться модом на публичных серверах, — это читерство, мод сделан не
для этого.

## Что понадобится

| | Версия | Зачем |
|---|---|---|
| Minecraft Java Edition | **26.2** (любая 26.2.x) | на другой версии jar откажется загружаться |
| [Fabric Loader](https://fabricmc.net/use/installer/) | 0.19.0 или новее | |
| [Fabric API](https://modrinth.com/mod/fabric-api) | любая сборка под 26.2 | обязательно |
| [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap) | 26.4.0 или новее | метки отдаются ей |
| [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map) | 1.44.0 или новее | карта, на которой метки рисуются |
| Java | 25 | идёт вместе с Minecraft 26.2 |

**Нужны оба мода Xaero.** Мод общается с миникартой, которая хранит метки, а видимыми
они сделаны только на большой карте. В файле мода оба объявлены как *рекомендуемые*, а не
*обязательные*: отсутствие одного из них запуску игры не мешает (Fabric Loader только
выведет предупреждение), но моду тогда нечего показывать. Что именно происходит в игре
без них, не проверялось. Разрабатывался и проверялся с Xaero's Minimap 26.4.2 и
Xaero's World Map 1.45.0.

**Только клиент.** На сервер ничего ставить не нужно, другим игрокам мод не нужен. Кому
нужны метки — тот ставит его в свою игру.

Xaero's Minimap и Xaero's World Map — отдельные продукты своего автора. Сюда они не
входят и частью этого репозитория не являются — скачивай их с официальных страниц.

## Установка

**1. Запусти Minecraft 26.2 с Fabric.** Если профиля Fabric ещё нет: скачай установщик с
[fabricmc.net](https://fabricmc.net/use/installer/), запусти, выбери версию Minecraft
26.2, нажми *Install*. Один раз запусти игру с новым профилем `fabric-loader-…-26.2` и
закрой.

**2. Скачай три мода, без которых этот не работает** — Fabric API, Xaero's Minimap,
Xaero's World Map (ссылки в таблице выше). На каждой странице выбирай файл под **Fabric**
и **26.2**.

**3. Скачай `oremap-0.5.0.jar`** со страницы
<https://github.com/svareyko/game-fixes/releases/tag/oremap-0.5.0>.

**4. Положи все четыре файла `.jar` в папку `mods`.**

| Система | Папка |
|---|---|
| Windows | нажми `Win+R`, вставь `%APPDATA%\.minecraft\mods`, нажми Enter |
| Linux | `~/.minecraft/mods` |
| macOS | `~/Library/Application Support/minecraft/mods` |

Если папки нет — создай. Если твой лаунчер держит отдельную папку игры для каждого
профиля, клади в папку `mods` того профиля, которым играешь.

**5. Запусти игру с профилем Fabric.**

### Как проверить, что всё встало

1. Открой одиночный мир и набери `/oremap status`. Если игра ответила строками
   `[Ore Map]`, как выше, — мод загружен. Если пишет *«Неизвестная или неполная команда»*
   (*Unknown or incomplete command*) — jar лежит не в той папке `mods` или запущен
   профиль без Fabric.
2. Спустись под землю — алмазы бывают ниже Y 16 — и набери `/oremap on`.
3. Открой большую карту Xaero. Через пару секунд вокруг тебя появятся бирюзовые метки `D`
   с подписями вроде `Diamonds x4 Y-57`.

В логе (`logs/latest.log`) при каждом запуске есть строка, начинающаяся с
`[oremap] loaded:`.

## Как убрать

Удали `oremap-0.5.0.jar` из папки `mods`. Это всё.

**Что будет с метками.** Они временные по замыслу: живут только в памяти и никогда не
записываются в твои файлы меток Xaero. Исчезают по `/oremap off`, при выходе из мира и
насовсем — когда убираешь мод. Твои собственные метки мод не трогает. В миры он ничего не
пишет, своего файла настроек у него нет. (Один безвредный след возможен в собственном
файле настроек Xaero для мира — см.
[Время жизни меток](docs/how-it-works.ru.md#5-время-жизни-меток).)

## Что незаметно выводит мод из строя

- **Обновление Minecraft.** Jar загружается только на 26.2. На 26.3 Fabric Loader откажет
  и прямо об этом скажет; мод нужно пересобрать под новую версию.
- **Обновление Xaero's Minimap.** Мод пользуется внутренними классами мода Xaero — открытого
  API для этого нет. Моды Xaero обновляются часто, и обновление может эти классы
  передвинуть. Мод сделан так, чтобы **выключиться, а не уронить игру**: `/oremap status`
  покажет `link to Xaero: BROKEN`. Возврат на предыдущую версию миникарты вернёт метки.
- **Лаунчер, который сам управляет папкой `mods`**, может удалить незнакомые ему файлы
  при переустановке или пересинхронизации профиля.

## Вопросы и ответы

**Это чит?**
На публичном сервере — да: видеть руду сквозь камень — это рентген, и именно поэтому мод
там работать отказывается. В своём одиночном мире — твоя игра, твои правила. См.
[Честная игра](#честная-игра).

**Может он показать руду по всей карте?**
Нет. Игра получает только чанки вокруг тебя, дальше показывать нечего. Иди — метки
двигаются вместе с тобой.

**Нажал `K`, ничего не произошло.**
Клавиши доходят до мода, только когда не открыт ни один экран. Закрой карту, нажми `K`,
посмотри на сообщение над горячей панелью — или просто набери `/oremap on`.

**Почему меток нет на миникарте?**
Намеренно: десятки меток погребли бы миникарту и завалили экран маяками. Если всё равно
хочется — убери строку с `setVisibility(...)` в
[`XaeroBridge.java`](src/oremap/XaeroBridge.java) и собери мод сам.

**У одной жилы две метки.**
Она лежит на границе чанков. Жилы склеиваются внутри чанка — так выгрузка чанка никогда
не оставляет висячую метку.

**Выкопал часть жилы, а число в подписи не изменилось.**
Метка снимается, когда пропадает нижний блок жилы; число блоков пересчитывается только
при повторном сканировании чанка.

**А железо, золото, изумруды?**
В скачанном виде — нет. Список блоков — это один короткий метод `targetOf` в
[`OreMap.java`](src/oremap/OreMap.java): поменяй и собери мод сам.

**Играем через виртуальную сеть (Hamachi, Radmin VPN, Tailscale…), пишет NOT ALLOWED.**
Эти программы выдают адреса вне частных диапазонов (`25.x.x.x`, `26.x.x.x`, `100.x.x.x`),
поэтому проверка считает их публичными. У того, кто держит мир, метки всё равно есть —
для него это одиночный мир.

**Домашний сервер на Paper, и метки врут.**
Серверы с защитой от рентгена прячут или подделывают руду в данных, которые отправляют
всем клиентам. Мод показывает только то, что получила твоя игра. Ванильный сервер и
сервер на Fabric присылают настоящие блоки.

**Работает с JourneyMap, VoxelMap или другой картой?**
Нет, только с картами Xaero. С Xaero's Better PVP, в который встроена та же миникарта,
не пробовали.

**Игра будет тормозить?**
Выключенный мод не стоит ничего. Включённый тратит 14–50 микросекунд на чанк (замерено на
настоящем мире) и сканирует не больше 16 чанков за тик, так что вход в мир с дальностью
прорисовки 32 не превращается в тысячи сканирований за один тик. Подробности — в разделе
[Сканер](docs/how-it-works.ru.md#2-сканер).

## Статус

Честно — что и как проверено.

**Проверено в игре** — 2026-09-06, ранняя сборка версии 0.2.0, одиночный мир, Minecraft
26.2, Xaero's Minimap 26.4.2 и World Map 1.45.0:

- метки появляются на большой карте Xaero;
- на миникарте их нет — подтверждено как желаемое поведение.

В той сборке метки были включены сразу. **Всё, что добавлено позже, по шагам не
проверялось:** выключено по умолчанию (поздняя 0.2.0), команда `/oremap` и клавиша `K`
вместо `O` (0.3.0), глубина в подписи (0.5.0). Версию 0.5.0 с тех пор включали в
одиночных мирах, и в логе игры видны включение и отсутствие ошибок связи с Xaero — но
никто не садился и не проверял эти функции по списку.

**В игре не проверялось никогда:**

- исчезновение метки выкопанной жилы;
- метки древних обломков в Незере;
- вход на сервер в локальной сети со второго компьютера — та часть проверки, которая
  пропускает локальные адреса и имена машин;
- молчание на публичном сервере — покрыто только самотестом правил для адресов;
- запуск игры без модов Xaero;
- сам выложенный jar: в сборках, которыми играли, тот же код, но сообщения в чате и
  подписи меток были на русском. Английские тексты только скомпилированы и прошли
  самотест.

**Проверяется автоматически при каждой сборке**, любая неудача сборку останавливает:

- исходники компилируются против настоящего клиентского jar Minecraft 26.2;
- каждый класс Minecraft и Xaero, на который ссылается мод, есть в установленной игре и
  миникарте (22 и 14 классов);
- самотест чистой логики: 22 адреса для проверки «где работать», включая ловушки
  `192.168.0.10.evil.com` и `localhost.example.com` и границы `172.16.0.0/12`; склейка

## Сборка из исходников

Здесь нет ни Gradle, ни Loom, и это не срезание углов: Minecraft 26.x поставляется
**необфусцированным**, ремапить нечего, хватает обычного `javac`. Сборка компилирует
против той игры, что у тебя установлена; из сети ничего не скачивается.

Нужны Python 3.8 или новее и установленный Minecraft 26.2 с Fabric Loader, Fabric API и
Xaero's Minimap. JDK берётся из собственного рантайма игры с Java 25 (в нём есть
`javac`); если его нет — из `JAVA_HOME`, затем из `PATH`, и тогда это должен быть JDK 25
или новее.

Скажи сборке, где игра. Ей нужна **папка профиля**: папка, в которой лежит клиентский
jar с именем самой папки (`<имя>/<имя>.jar`) и папка `mods` с Fabric API и Xaero's
Minimap. У лаунчеров, которые держат каждый профиль в своей папке `versions/<имя>`, всё
это уже есть. Либо задай переменную окружения:

```
set MC_PROFILE_DIR=<папка игры>\versions\<имя>
python build.py build
```

(в Linux и macOS: `export MC_PROFILE_DIR=...`)

либо создай рядом с `build.py` файл `build_local.py` (git его игнорирует):

```python
PROFILE_DIR = r"<папка игры>\versions\<имя>"
```

У официального лаунчера эти части лежат в разных местах, поэтому собери такую папку
руками: создай `26.2\`, скопируй в неё `versions\26.2\26.2.jar`, добавь папку `mods` с
jar-файлами Fabric API и Xaero's Minimap и укажи на неё `MC_PROFILE_DIR`.

Если игра лежит не в `%APPDATA%\.minecraft`, задай ещё `MC_GAME_DIR` (или `GAME_DIR` в
`build_local.py`): оттуда берутся библиотеки игры и рантайм Java.

| Команда | Что делает |
|---|---|
| `python build.py build` | компилирует, прогоняет все проверки из раздела [Статус](#статус), пишет `build/oremap-<версия>.jar` |
| `python build.py install` | собирает и копирует jar в `<профиль>/mods`, удаляя старые `oremap-*.jar`. Игру перед этим закрой |
| `python build.py uninstall` | удаляет `oremap-*.jar` из `<профиль>/mods` |

Под другую версию Minecraft: поменяй диапазон в
[`resources/fabric.mod.json`](resources/fabric.mod.json) и запусти сборку — проверка
ссылок перечислит все переехавшие классы. См.
[Перенос](docs/how-it-works.ru.md#8-перенос-на-новую-версию-minecraft-или-xaero).
