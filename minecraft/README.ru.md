Три небольших мода; каждый написан потому, что готового под Minecraft 26.2 не нашлось.
Они независимы: ставьте один или все.

## Что нужно каждому моду

- **Minecraft 26.2** с **[Fabric Loader](https://fabricmc.net/use/installer/) 0.19.0 или новее**
- **[Fabric API](https://modrinth.com/mod/fabric-api)** для 26.2
- Java 25 — лаунчер ставит её вместе с игрой

## Установка

1. Поставьте Fabric для Minecraft 26.2 [установщиком Fabric](https://fabricmc.net/use/installer/),
   один раз запустите игру с профилем *fabric-loader* и закройте.
2. Откройте папку игры: нажмите **Win + R**, введите `%APPDATA%\.minecraft`, нажмите Enter. Внутри
   есть папка `mods` (если нет — создайте). Некоторые лаунчеры держат отдельную папку игры на
   каждый профиль — путь виден в их настройках.
3. Скачайте `.jar` мода со страницы [Releases](https://github.com/svareyko/game-fixes/releases) —
   файл называется как мод, например `hamster-0.5.1.jar`, — и
   [Fabric API](https://modrinth.com/mod/fabric-api) и положите оба в `mods`.
4. Запустите игру. В главном меню список модов (если стоит [Mod Menu](https://modrinth.com/mod/modmenu))
   покажет мод.

Моды с пометкой *на клиенте и на сервере* добавляют новые блоки, предметы или мобов: на сетевом
сервере они должны стоять и на сервере, и у каждого игрока. Моды *только на клиенте* ставятся лишь
на свой компьютер.

Чтобы убрать мод, удалите его `.jar` из `mods`. В README каждого мода сказано, что при этом станет
с тем, что он добавил в ваш мир.

## Собрано без Gradle

Minecraft 26.x поставляется необфусцированным, и обычной связке (Loom и маппинги) делать больше
нечего. Каждый мод собирается обычным `javac` через свой `build.py` — против той игры, что уже
установлена; каждая сборка прогоняет самопроверку и валидатор. Подробности — в
`docs/how-it-works.ru.md` каждого мода.
